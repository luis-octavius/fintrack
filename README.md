# FinTrack

This app is intended, initially, to be a manager for bills. It helps to keep track of: 
- The bills that you have to pay each month
- How many parcels you've already paid or you'll have to pay for a certain bill
- What you spend your money (almost entirely)

# Technologies 
I wanted to do this in these technologies, mostly because I am studying them:
## Backend
- C#
- .NET 10
- Entity Framework

## Frontend
- TypeScript
- React
- Tanstack Query
- Tanstack Table
- Axios
- MUI
